## 🚀 How to Run Locally

Make sure you have **Python 3** installed on your system.

1. **Clone the repository:**
   ```bash

   cd LeetCode-Solution
   ```

2. **Run any solution script:**
   ```bash
   python "Problems/1-Two Sum.py"
   ```
